\chapter{Supplementary Tables and Figures}
\label{app:tables}

These tables and figures give the breakdowns the results chapters summarise --- among them
Figure~\ref{fig:nmssel} on window-geometry selection, Figure~\ref{fig:r1_strata} on annotated
object support by class, and Figure~\ref{fig:rd_examples} on zero-shot recall by stratum. The tables are
generated directly from the same artefacts the chapters read, by the script
\texttt{make\_appendix\_\allowbreak tables.py}, so no value here is transcribed by hand and none can
drift from the main text.

Nothing already shown clearly in the main body is repeated. What is added is the detail those
chapters compress: every CFAR variant rather than the per-condition best, both matching gates rather
than the primary one, per-condition localisation rather than the pooled figure, the per-sequence and
per-seed real-data results, and the full stratum breakdown.

All synthetic values are from the held-out split at the final suppression radius of
\ProtocolNms{}; all real-data values are from the revised evaluation described in
Appendix~\ref{app:prereg}.

\label{fig:r0_footprint}

CARRADA also publishes a bounding box per object, and it is tempting to treat it as the extent of
the dense mask. It is not: the box is strictly smaller than the dense support on both axes in every
one of the \CarradaObjectFrames{} instances, so the two describe different annotation constructs.
Quoting one while meaning the other would understate object extent by roughly a quarter.
